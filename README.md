# NFT Showcase - Sneaker & CryptoPunk NFTs

This project is a mockup website designed to showcase and sell NFTs (Non-Fungible Tokens), focusing on high-value fictional items like a "Sneaker NFT" and a "CryptoPunk NFT." The site demonstrates web development skills using HTML, CSS, and responsive design techniques.

## Features

- **Responsive Design**: The layout adapts to various screen sizes, ensuring a smooth experience on both desktop and mobile devices.
- **Custom Buttons**: Button styles refactored with reusable classes using the BEM naming convention.
- **CSS Variables**: Implemented for consistent styling and easier maintenance.
- **Humorous Content**: The site includes satirical descriptions of NFTs, adding a playful tone to the mockup.
- **Typography & Color Scheme**: Carefully chosen font styles and colors to match the theme of luxury and exclusivity.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling the webpage, including custom button styles and responsive design.
- **Google Fonts**: For typography (`Roboto` font).
- **Normalize.css**: To reset browser default styles and ensure consistency across different browsers.

**Getting Started**

To view and explore this project locally, follow these steps:

Clone the repository:

```bash
git clone https://github.com/your-username/nft-showcase.git
```
Navigate to the project directory:

```bash
cd nft-showcase
```
Open index.html in your preferred web browser.
